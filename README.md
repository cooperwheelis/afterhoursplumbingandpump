# After Hours Plumbing Rebuild

Create a complete, responsive multi-page website for After Hours Plumbing and Pump Service, a locally owned plumbing company based in Hillsborough, North Carolina.

Current website:
https://afterhoursplumbingandpump.com/

Visual layout reference:
https://biggersmarket.com/

Use Biggers Market only as inspiration for its clean structure:

* Slim announcement bar
* Compact navigation
* Full-width photographic hero
* Short text placed directly over the hero image
* One prominent rectangular CTA
* Sharp, editorial layout
* Warm off-white page backgrounds
* Strong typography
* Full-width image sections
* Simple navigation and minimal copy

Do not copy Biggers Market’s brand, content, green color palette, or ecommerce components.

## Primary objective

The website’s main conversion is an immediate phone call.

After Hours Plumbing offers actual 24/7 emergency plumbing service throughout its full service area. The phone number must always be easy to find and use:

(919) 732-7588

Every phone CTA must use a working `tel:+19197327588` link.

The website should feel:

* Friendly and local
* Clean and premium
* Professional
* Dependable
* Calm during an emergency
* Easy for an average homeowner to understand
* Significantly more modern than the current site
* Familiar enough that existing customers still recognize the company

The result should not resemble a generic SaaS template, corporate franchise website, or overly playful home-services design.

## Visual system

### Colors

Use colors inspired by the existing logo:

* Deep navy as the main brand color
* Strong medium blue as a secondary color
* Warm off-white for page backgrounds
* Dark charcoal for body text
* Muted gray for supporting text
* Amber-orange used sparingly for the most important Call Now buttons

Amber buttons should use dark-navy text if that produces better contrast than white.

Do not use large red overlays, bright gradients, or too many competing accent colors.

### Typography

Use:

* Inter Tight or a similar modern, sturdy sans-serif for headings
* Inter or a similar highly readable sans-serif for body text

Typography should feel professional and straightforward.

Avoid:

* Decorative scripts
* Condensed fonts
* Oversized headings that consume most of the screen
* Long all-capital paragraphs
* Center-aligning large blocks of copy

### Shape language

Use sharp, architectural shapes.

* Zero to two pixels of corner rounding
* Rectangular buttons
* Straight section boundaries
* Thin borders
* Restrained shadows only when required for separation
* No pill-shaped cards
* No bubbly interface elements
* No excessive floating panels

### Spacing

Use a maximum content width around 1,200 pixels.

Suggested spacing:

* 64–80 pixels between major desktop sections
* 40–56 pixels on mobile
* 24–32 pixels between related elements

Do not create giant blank areas or sections that are taller than their content requires.

## Images

Prioritize real After Hours photographs.

Do not use these apparent stock assets:

* `shutterstock_2492516645.jpg`

* Automatic hero sliders

* Constant movement
* Large animated counters

## Accessibility

Target WCAG 2.2 AA.

Include:

* Skip-to-content link
* Semantic header, navigation, main, sections, and footer
* Exactly one clear H1 on every page
* Logical H2 and H3 hierarchy
* Descriptive link text
* Meaningful image alt text
* Keyboard-accessible navigation
* Visible focus states
* Minimum 4.5:1 text contrast
* Properly associated form labels
* Accessible error and success messages
* No icon-only links without accessible names
* No automatic moving content
* Reduced-motion support
* Adequate zoom and responsive reflow

Do not place essential text inside images.

## SEO requirements

Implement:

* Clean descriptive URLs
* Unique title tag and meta description for every route
* Canonical URLs
* XML sitemap
* Valid robots.txt
* Open Graph metadata
* Descriptive image filenames and alt text
* Breadcrumbs on supporting pages
* Strong internal links between services and locations
* `Plumber` or appropriate `LocalBusiness` structured data
* `Organization`, `Service`, and `BreadcrumbList` structured data where appropriate

* Correct 24/7 emergency availability
* No default WordPress posts
* No links to the old WP Engine staging domain
* No `?page_id=` URLs
* No duplicated Mebane listing
* No fake review schema or invented ratings

The visible content should remain more important than SEO repetition.

## Content style

Write at approximately a sixth- to eighth-grade reading level.

Use:

* Short headings
* Short paragraphs
* Familiar language
* Active voice
* Calm reassurance
* Clear next steps
* Specific service terms customers understand

Avoid:

* Marketing jargon
* Keyword stuffing
* “Best plumber” claims
* “Unbeatable rates”
* Long introductions
* Repeating “Triangle Area North Carolina” unnaturally
* Excessive exclamation points
* Generic AI-sounding language
* Claims that cannot be verified

## Functional requirements

Ensure that:

* Every phone button works
* Navigation and dropdowns work on desktop and mobile
* Forms validate correctly
* Links point to the intended route
* The mobile call bar works
* No empty buttons are visible
* Active-navigation colors remain readable
* The real North Carolina service area is shown
* No page has oversized blank space
* Header and footer remain consistent
* The website is responsive at 375, 768, 1024, and 1440 pixels

The final website should feel like a modern, established local plumbing company that answers the phone when customers need help, not a large franchise and not an outdated contractor template.
